## Outcomes (2026-11-15)

Scope (Alper): burnlint doesn't evaluate output; the user's tests or evals supply pass/fail and burnlint joins it to cost. Design reviewed independently by Fable 5.2 before building; Alper took all its answers:
- Gate: a separate `--fail-success-drop <points>`, never folded into `--fail-above` (a published flag would change meaning with another option, and percent would mix with percentage points). Exit 1 on a clear drop over the threshold, 2 when a compared run has no outcome, 0 with a warning when the runs can't show a drop.
- Errored bench runs: `pass:false` when the agent hit its own limit (turns, run cap, output cut off: `ModelBehaviorError`), no row for outside failures. The Python bench caught everything in one `except` and wrote no grade; now split. The AI SDK bench already graded a stopped run on its (empty) answer.
- Extra keys in a row: ignored, never printed; a missing `pass` names a near-miss key (`passed`, `Pass`, ...); errors carry line numbers and keys, never values.
- Its design changes, all made: success counts runs that cost per run leaves out (no priced call); a compared run without an outcome makes the success verdict `can't tell`; a file matching no run exits 2; whole-id matching, case folded only for hex and UUIDs (base64 is case-sensitive); "no passes" instead of a number; the test runs on failures so the one-sided branch tests a drop, and "lower" success is shown red.
- Its power numbers (the existing permutation test on 0/1, one-sided p < 0.05): 1 group x 3 runs never shows a drop (3/3 -> 0/3 is p = 0.05 exactly); 1 x 5 shows 5/5 -> 1/5; 3 tasks x 3 shows 9/9 -> 4/9; 3 x 5 shows 15/15 -> 10/15. A true 90% -> 70% fires 7% (3x3) and 24% (3x5). A/A at 90%: 0.1% and 0.8% false alarms. One group per input makes it a sign test (5 flips, none back: p = 0.031), so `--group-by` now keeps the key it names even if the content filter would drop it (`bench.input_id`).

Checked on `captures/agents-2.jsonl` with an outcomes file built from the bench's grades (22 runs with an outcome, 17 passed): cost per successful run $0.085161 from burnlint, $0.08515 from the bench's own usage (`usd` rounded to 4 decimals per run). `diff` normal vs prefix (explain + principle, 3 runs each): cost +34%; success 6/6 -> 5/6, "too few runs to tell", as it should be at 3 runs; cost per success $0.032 -> $0.052, which checks by hand at base's mix. Fixture `openai-agents-outcomes.jsonl`: the bench's grades for the four committed OpenAI Agents SDK traces. The bench changes were run in mock mode (no key): the turn-limit path and the graded path both work; mock runs write no outcome rows.
